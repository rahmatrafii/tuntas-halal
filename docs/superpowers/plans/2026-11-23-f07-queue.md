# F07 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement inline. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Antrean staf nyata dengan urutan tindakan, pencarian/filter server dan paginasi.
**Architecture:** Server Component memverifikasi LP3H melalui guard existing. Query pengguna/RLS menggabungkan cases/contact, menghitung kelompok lalu mengambil 20 baris halaman; form GET dan aksi menuju F05/F06 existing.
**Tech Stack:** Next.js 16.4.6, TypeScript strict, Supabase/PostgREST 14, CSS/token existing; tanpa dependency atau migrasi baru.
**Spec:** `docs/superpowers/specs/2026-11-23-f07-queue-design.md`

## Global Constraints

- Status hanya needs_sending, awaiting_reply, needs_review, completed; Hubungi hari ini adalah kelompok.
- Seluruh query memakai user client, scope organisasi dan assignee pendamping; koordinator read-only. Tanpa data/undangan/pesan nyata.
- Kontrol 48px, form 16px, warna/token/desain existing; input GET tanpa JS bekerja.
- Pertahankan perubahan F06; tidak ada commit/push/deploy atau fixture cloud tambahan.

## Review Focus

- OR nama/ref dan tanda khusus tidak memperluas pencarian atau scope (Task 1/3).
- Hari UTC berbeda dengan LP3H dan tanggal null/today/future (Task 1).
- Kelompok membentang halaman, tie order, page berlebih, count error (Task 1/3).
- Koordinator/transfer/revocation tidak memperoleh aksi tulis atau data luar akses (Task 2/3).
- Filter aktif tersimpan di pagination, tanpa hasil bukan error layanan, input duplikat/panjang tidak merusak form (Task 1/2).
