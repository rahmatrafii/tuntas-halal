# Perapihan UI mobile

> Kerjakan di checkout aktif karena antrean dan pengalihan yang sedang diperiksa masih memuat perubahan lokal. Verifikasi setiap perubahan perilaku dan lakukan review visual setelah implementasi.

**Tujuan:** Pendamping melihat revisi yang perlu dikerjakan dari layar pertama dan bisa menemukan aksi utama tanpa membaca ulang setiap blok.

**Arah desain:** Kanvas putih, panel abu-abu, aksi utama hitam dan status pastel. Antrean menempatkan daftar di bawah pencarian ringkas. Detail mengutamakan progres dan pekerjaan revisi. Draf merangkum pilihan dalam pengungkapan yang bisa dibuka. Aksi setelah pengiriman tetap terpisah.

- [x] Ringkas navigasi, pencarian, kartu dan daftar. Audit kembali posisi kartu teratas pada 375 px.
- [x] Susun ulang detail kasus dan draf. Cek pengungkapan pilihan, pemulihan draf, ekspor dan jalur membuka draf sesudah seluruh revisi tuntas.
- [x] Tampilkan konfirmasi dan tanggal sesuai pilihan formulir. Pertahankan pengiriman form native. Verifikasi payload dan tampilan pengalihan dengan kode akun ringkas dan kode lengkap tersedia.
- [x] Rapikan login, akun dan navigasi/aksi demo. Jalankan check, build dan pemeriksaan Chromium, lalu catat batas bukti perangkat.

Pada layar 375 × 812 px, tombol **Siapkan pengingat** mulai pada 728 px dibanding sebelumnya 1.026 px. **Buka WhatsApp** mulai pada 657 px dibanding sebelumnya 1.619 px. Review kode menemukan jalur draf tersimpan sempat hilang ketika semua revisi selesai. Tautan **Kelola draf WhatsApp** tersedia lewat Informasi kasus bagi pendamping yang ditugaskan.

Lint, TypeScript, dan build produksi lulus. Pengulangan `npm run check` tersendat pada tahap tes setelah lint dan TypeScript lulus. Seluruh 133 tes lulus saat dijalankan ulang dengan dua worker. Chromium memeriksa 24 kombinasi layar dan ukuran memakai data fiktif lokal. Keyboard HP, zoom 200%, dan perangkat peserta tetap perlu diperiksa.
