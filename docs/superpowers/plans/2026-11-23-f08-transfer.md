# F08 — Tampilan koordinator dan transfer kasus

**Cakupan:** daftar kasus satu LP3H, filter pendamping di server, konfirmasi transfer ke pendamping aktif, audit, dan isolasi setelah transfer. Gunakan shell staf monokrom dan kontrol native yang mengikuti sistem desain. Checkout fitur saat ini mengandung F06/F07 dan dipertahankan.

Pilih perluasan daftar kasus dan satu halaman konfirmasi khusus. RPC transfer dan RLS yang ada menangani otorisasi, versi, idempotensi dan audit. Daftar anggota hanya membaca ID akun dan status dari membership LP3H. Label memakai kode akun lengkap karena tidak ada profil staf; filter mencakup akun nonaktif untuk menemukan kasus yang masih ditugaskan. Hanya akun aktif yang dapat menjadi penerima.

- [x] Tes service dulu: konfirmasi, peran/LP3H, konflik dan retry dengan ID intent stabil. Implementasikan transfer melalui user client dan RPC existing.
- [x] Tambah filter GET, kode penanggung jawab, konfirmasi native/hydrated, hasil/error dan riwayat. Gunakan halaman tersendiri agar bisa dibuka dan ditinjau tanpa JavaScript.
- [x] Uji lokal melalui Auth/HTTP untuk filter, konfirmasi, konflik/retry, audit, dan hak akses sesudah transfer. Check lulus 130 tes, lint dan TypeScript. Build lulus. Review independen tidak menemukan masalah yang perlu ditindaklanjuti.
- [x] Uji alur yang sama pada cloud development memakai fixture terisolasi dan verifikasi cleanup. Run pertama berhenti pada asumsi pengalihan, dibersihkan dan dikonfirmasi nol.
